# MSc Project Code Skeleton

This folder contains the starting structure for the MSc project implementation.

## First step

1. Copy `ujiindoorloc.zip` into `data/raw/`.
2. From the project root, run:

```bash
python src/01_dataset_inspection.py
```

3. Review outputs in:

- `results/tables/dataset_profile.json`
- `results/tables/dataset_columns_summary.csv`
- `results/experiment_logs/01_dataset_inspection_summary.txt`

Do not start model training until dataset inspection has been reviewed.
